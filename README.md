## 🛠 Ключевой проект
### 🔹 [HardwareStoreMBT](./projects/HardwareStoreMBT) — Система автоматизации магазина
* **Что это:** Полноценное десктопное приложение для комплексного учета товаров, заказов, сотрудников и складских запасов магазина техники.
* **Что сделано (каким способом):**
  * Спроектирована архитектура приложения на базе **WPF (C#)** с использованием паттернов проектирования.
  * Настроено подключение к реляционной базе данных через **Entity Framework** для безопасного хранения и обработки информации.
  * Реализована ролевая модель доступа (Администратор, Менеджер, Клиент) с разграничением прав на уровне интерфейса.
  * Добавлен функционал генерации отчетов и экспорта данных.
