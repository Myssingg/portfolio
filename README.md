## 🚀 Как запустить

```bash
# клонировать вместе со всеми проектами
git clone --recurse-submodules https://github.com/Myssingg/portfolio.git

# если клонировали без флага, подтянуть подмодули отдельно
git submodule update --init --recursive
```

Для проектов с базой данных:

1. Откройте `script.sql` (или `script.txt`) из нужного проекта в SSMS и выполните его, чтобы создать БД.
2. Проверьте строку подключения в `App.config` и при необходимости измените имя сервера.
3. Откройте `.sln` в Visual Studio и запустите проект.
